🔥 First alert in 5 minutes

FireWatch watches a hot-work zone, detects fire and smoke, checks that an extinguisher and an observer are present, and on danger saves a frame, logs it and sends an alert.

1

Running on a webcam

The default source is your laptop camera. Run it from your own terminal (macOS will not grant camera access to a background process):

cd ~/Documents/bi/firewatch
source .venv/bin/activate
uvicorn app.main:app --port 8010
macOS will ask for Camera access — allow it (or System Settings → Privacy & Security → Camera). Close Zoom / FaceTime if they hold the camera.

Open http://127.0.0.1:8010/ — the Monitoring tab.

2

Define the hot-work zone

On Monitoring, click Set zone under the video, click to outline the area (3+ points) and press Save. Fire only counts when it is inside the zone, which filters out sparks and glare at the frame edges.

3

Test detection

Hold a lighter, a candle or a flame video on your phone up to the camera. A red fire box appears in the zone, the event counter increases, and a row with a proof frame is added to the Event log.

The alert does not fire on the first frame: fire must persist for several consecutive frames (false-positive filter), and repeats per zone are limited to once every 60 seconds.
4

Permit conditions: what the badges mean

  • yes — condition met (observer / extinguisher found in the zone);
  • no — not found in the zone;
  • n/a — check not configured (no model). The observer check uses the standard model; for the extinguisher, put your own weights in models/ext.pt.
5

Telegram alerts

Create a bot via @BotFather, find your chat_id, then:

cp .env.example .env   # fill in TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID

Restart the server — on an event, a photo with the zone, time and condition status arrives in the chat. The Telegram badge at the top will read "configured". You can also set webhook_url in config.yaml.

6

Event log and permit linking

The Event log tab is a table with date and zone filters, proof frames and condition status. A work permit number can be entered directly on the event row or on Monitoring, where it attaches to the latest event.

7

Tuning — config.yaml

  • video_source — 0 (camera), rtsp://… or a file path;
  • detection.conf_threshold — confidence threshold (higher = fewer false positives);
  • detection.persistence_frames — consecutive frames required to alarm;
  • detection.alert_cooldown_sec — pause between repeated alerts.

Switch the source quickly without editing the file: FIREWATCH_VIDEO_SOURCE=0 uvicorn app.main:app --port 8010

8

Offline demo (no camera)

A synthetic clip plus the demo detector shows the whole pipeline without real fire:

python scripts/make_demo_video.py
FIREWATCH_VIDEO_SOURCE=data/demo_fire.mp4 FIREWATCH_FIRE_WEIGHTS=mock uvicorn app.main:app --port 8010
